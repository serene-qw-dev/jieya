# 解压研究所 Windows 桌面版 v1.1.1

一个离线优先的桌面解压小工具，使用 Electron + HTML/CSS/JavaScript。原有玩法继续保留，本版增加了白噪音、自由绘画、无限捏泡泡、主题与音量设置、每日心情日历。

## 功能一览

### 保留的原有功能
- **木鱼修行**：点击音效、功德统计、木鱼形态升级。
- **限时捏泡泡纸**：40 颗泡泡、彩蛋、连击、计时、成绩记录。
- **锤爆烦恼**：30 秒反应小游戏、分数和最佳成绩。
- **今日求签**：每日一签、历史记录（仅供娱乐）。
- **我的档案**：解压等级、成就墙、历史统计。

### v1.1.1 修复
- 锤烦恼改为局部更新游戏区域，避免目标出现时整页刷新导致滚动位置跳动。
- 为每个洞增加目标代次标记，旧计时器不会提前隐藏新目标。
- 调整视口高度与内容滚动容器，改善小窗口上下滚动。

### v1.1.0 新增功能
- **白噪音小屋**：雨声、海浪、森林氛围由 Web Audio 在本机实时生成；支持音量控制和全屏放松动画，不依赖外部音频文件。
- **沙子绘画**：使用鼠标或支持触摸的设备绘画，选择六种彩砂颜色、调整颗粒大小、清空画布，并导出 PNG 图片。
- **无限捏泡泡**：无倒计时、无输赢，泡泡会自动补充；累计次数保存在本机。
- **四套主题**：柔和薰衣草、海盐蓝、森林绿、日落橘；支持游戏音效开关与音量调节。
- **每日心情日记**：六种心情、可选文字、月历、按周回顾。所有数据仅存于本地，不会自动上传或同步。
- **应用图标与说明**：更新图标、README 和自动发布说明。

## 在 Windows 上运行

推荐安装 Node.js 24 LTS：<https://nodejs.org/>。首次安装依赖时需要联网。

### 最简单的方法
1. 解压本项目到一个普通文件夹。
2. 双击 `运行开发版.bat`，或双击 `一键生成Windows安装包.bat`。
3. 一键打包完成后，安装程序和便携 ZIP 位于 `dist` 文件夹。

### 手动命令
在本文件夹打开 CMD：

```cmd
npm install
npm start
```

确认开发版可以运行后：

```cmd
npm run dist:win
```

生成文件：
- `dist/解压研究所-1.1.1-Windows-x64.exe`：Windows 安装程序。
- `dist/解压研究所-1.1.1-Windows-x64.zip`：便携包。

需要在 Windows 上本地构建，或者使用下文的 GitHub Actions 自动构建。

## 更新你现有的 GitHub 仓库

如果你要更新之前的 `kiss061012/jieya` 仓库，请先备份当前项目，再把本项目文件覆盖到仓库中的 `desktop-app` 目录（不要删除仓库根目录的 `.git` 文件夹）。同时保留/更新根目录的 `.github/workflows/release-windows.yml`。

在仓库根目录的 CMD 中执行：

```cmd
git add .
git commit -m "发布解压研究所 v1.1.1"
git push
git tag v1.1.1
git push origin v1.1.1
```

随后打开仓库的 **Actions** 页面，等待 `Build Windows release` 工作流成功；它会把 `.exe` 和 `.zip` 自动附加到 GitHub Release。

下载页：<https://github.com/kiss061012/jieya/releases/latest>

> 如果 `v1.1.1` 标签已经存在，不要重复创建同名标签，应换用 `v1.1.2` 等新版本号。不要使用 `git push --force`。自动发布需要仓库 Actions 权限可用。

## 数据与隐私

统计、心情、主题、音量与游戏进度使用浏览器本地存储（localStorage），默认不发送到网络；白噪音在本机由 Web Audio 合成。卸载与重装可能保留或清除本机数据，重要记录建议自行备份。软件目前没有代码签名证书，Windows 可能对新软件显示 SmartScreen 提示，请只从你信任的发布页下载。

## 已知说明
- 环境音为实时合成氛围音，不是高保真自然环境录音；效果因扬声器/耳机而异。
- 沙子绘画画布在离开页面后会重新初始化，因此请先点击“保存为图片”保留作品。
- 每日心情记录默认只存本机，清除应用数据或重置数据后无法恢复。
- 今日求签为随机娱乐内容，不用于预测现实事件或作出重要决定。

## 技术栈
Electron、原生 HTML/CSS/JavaScript、Web Audio API、Canvas API、electron-builder。
