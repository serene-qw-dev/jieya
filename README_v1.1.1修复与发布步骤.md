# 解压研究所 v1.1.1 修复与发布步骤

本次针对 v1.1.0 中「锤烦恼」和垂直滚动异常提供热修复。

## 修复内容
- 锤烦恼出现目标时不再每几百毫秒重绘整个应用，避免上下滚动跳动。
- 点击目标后只更新游戏区域、分数与连击，保留当前滚动位置。
- 为每个洞增加目标代次标记，旧计时器不能再提前隐藏新目标。
- 修复视口最小高度可能让小窗口页面溢出的布局设置。

## 覆盖步骤
1. 备份 `D:\小程序` 文件夹（尤其不要删除 `.git`）。
2. 把这个 ZIP 解压到 `D:\小程序`，遇到同名文件选择替换。
3. 在 CMD 逐条执行：

```cmd
cd /d D:\小程序
git status
git add .
git commit -m "修复锤烦恼和页面滚动问题 v1.1.1"
git push
git tag v1.1.1
git push origin v1.1.1
```

4. 打开 https://github.com/kiss061012/jieya/actions 检查 `Build Windows release`。
5. 构建成功后打开 https://github.com/kiss061012/jieya/releases/latest 下载 v1.1.1 安装包。

## 注意
- 每条 CMD 命令单独按回车。
- 如果提示标签 `v1.1.1` 已存在，不要强制覆盖，先查看 GitHub Releases 和本地标签。
- 请在本机实际测试上下滚动、锤击、目标消失、分数和音效后再分享新版。
- 这里提供的是修复源码与自动构建配置，未在当前环境实测生成 Windows EXE。
